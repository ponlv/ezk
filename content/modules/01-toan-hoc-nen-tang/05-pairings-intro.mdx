## Sẽ học gì trong bài này

- **Định nghĩa: bilinear pairing** — `e: G_1 × G_2 → G_T`, ba tính
  chất bilinear / non-degenerate / computable.
- **Vì sao bilinearity = phép thuật** — scalar `a, b` "chui" ra ngoài
  thành lũy thừa, cho phép verify scalar relation qua group element.
- **Trực giác: pairing ép mọi thứ vào field "khổng lồ"** — `G_T = F_(p^k)*`,
  embedding degree `k`.
- **Ba "loại" pairing** — Type 1, 2, 3; vì sao Type 3 (BN254, BLS12-381)
  là chuẩn hiện đại.
- **Một vài identity quan trọng** — `e(P + P', Q) = e(P, Q) · e(P', Q)`,
  `e(𝒪, Q) = 1`, ...
- **Vì sao pairing-based SNARK phổ biến** — Groth16 verify chỉ 3 pairing,
  proof ~200 byte; trade-off với trusted setup.
- **Code: ta sẽ chưa implement pairing** — Miller's algorithm + final
  exponentiation phức tạp; module 2 sẽ dùng `ark-bn254`.
- **Bài tập (giấy bút)** — pairing-based DH equality check, đọc EIP-197.
